#
#   py-clob-client 0.22.0 pins  eth-account===0.13.0  (strict, triple-equals)
#   web3           <7.0.0 pins  eth-account<0.13      (incompatible)
#   web3           >=7.0.0      eth-account>=0.13.0   (compatible)

# eth-account 0.13.x in turn requires hexbytes>=1.2.0 and eth-rlp>=2.1.0, which
# web3 7.x accepts. Pinning hexbytes explicitly avoids the resolver picking
# hexbytes 0.x (which is what triggered the "hexbytes conflicts" message).
